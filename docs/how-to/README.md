# How-to guides

Short, narrated screen-capture videos of the real KageOps app — no mockups,
no staged UI. Each video is produced by an automated pipeline that drives the
actual application and records it, so guides are regenerated whenever the UI
changes and never drift from the product you're running.

## What episode 01 covers

1. What the six-step first-launch wizard configures and why it exists
2. Choosing a model preset — quality vs cost trade-offs, per-agent models, CLI install commands
3. Trust levels: how much the agents do without asking you
4. API keys: stored in your operating system's keychain, never plaintext
5. The per-run budget kill-switch (why "fifty cents" is a real safety feature)
6. Landing in the New Project flow with your defaults pre-wired
