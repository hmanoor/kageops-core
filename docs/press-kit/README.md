# Press kit

Screenshots of the real KageOps app, pulled straight from the frames of the
[how-to video series](../how-to/README.md) — no mockups, no staged UI.

Free to use for write-ups, reviews, and posts about the project.

| File | Shows |
|------|-------|
| `00-hero-grid.png` | Four-panel overview — best single image for social posts |
| `01-live-run-approval.png` | A live run paused at a phase gate, waiting for human approval |
| `02-phase-progress.png` | The six-phase pipeline ticking off, with approval history |
| `03-model-presets.png` | Model routing — which model runs which agent, per preset |
| `04-cost-intelligence.png` | Real per-agent / per-provider spend against a budget cap |
| `05-artifact-browser.png` | Generated files with a live preview of the built page |
| `06-headless-gate-refusal.png` | The CLI's acceptance gate refusing to sign off incomplete work |

Direct-link any of these with a raw URL, e.g.

```
https://raw.githubusercontent.com/hmanoor/kageops-core/main/docs/press-kit/00-hero-grid.png
```

Logos and wordmarks live in [`assets/branding`](../../assets/branding).
